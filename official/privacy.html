Server Monitor

Privacy

Server Monitor is built so that your data stays with you: on your iPhone and on your servers. There is no appinsource backend and no account.

This website

  • No cookies, no analytics, no embedded fonts or scripts from other companies. The page makes no request to any server other than the one it is served from.
  • Your theme choice (Auto, Light or Dark) is kept in your browser's local storage and never sent anywhere.
  • The web server keeps ordinary access logs for operating the site. They are not shared.

The app

  • On your iPhone: the private SSH key the app generates, in the Keychain; the servers you added, with their addresses and host keys; alert rules; your member signing key if you join a team. Face ID is used only to unlock the app and is handled by iOS.
  • On each server: the agent and its config file, readable by root only. The config holds the server name, alert rules, the member list and, if you use push alerts, your Apple push key.
  • On the relay, if you run one: server names, member names, roles and scopes, and tokens and invites as SHA-256 hashes. The relay passes requests between members' phones and your agents and does not keep metrics or logs.
  • Push notifications: sent from your server to Apple's push service with your own key. appinsource is not involved.
  • What we receive: only what you write to us by email.
